# AGV 智能仓储调度平台

能仓储调度平台是智能物流体系中的核心调度中枢，作为衔接上层 WMS、MES 系统和底层 AGV 搬运设备的管控软件，可实现多台机器人集群协同作业，完成仓库物料自动转运，助力制造工厂、电商仓储实现内部物流自动化升级，减少人工搬运成本，提升仓储流转效率。平台兼容潜伏式、料箱式、叉车式等多种型号 AGV，开放标准化接口，支持项目二次开发，搭配 PC 控制台与移动端，管理人员可随时随地监控仓储作业状态。

平台核心能力为智能任务分配与动态路径规划。系统接收出入库、拣货、补货等任务后，依据 AGV 实时位置、剩余电量、负载情况，自动匹配最合适的设备执行作业。依托仓库电子地图实时计算最优行进路线，内置交通管制与智能避障算法，自动处理 AGV 交汇、拥堵、死锁等问题。遇到紧急订单可提升任务优先级，同时监测机器人电量，电量偏低时自动调度前往充电桩，保障集群不间断作业。

可视化监控模块可展示仓库数字地图，直观查看每台 AGV 的实时位置、运行速度、任务进度与故障信息。一旦设备离线、卡顿或者出现异常告警，系统会及时推送提醒至 PC 与移动端，运维人员快速定位故障点位。后台自动统计作业数据，记录搬运任务总量、设备利用率、任务完成时长，生成仓储物流报表，管理者以此优化库位布局和作业流程，持续压缩物料搬运耗时。

平台具备精细化权限管理，支持管理员、运维、操作员多角色账号划分，严格管控操作权限。完整留存任务日志、设备运行记录，便于问题追溯。标准化 API 接口能够无缝对接 WMS 仓储、MES 生产执行、ERP 企业资源系统，打通订单、库存、生产、物料搬运全链路数据，消除信息孤岛。系统支持本地私有化部署，可根据仓库面积、业务流程、设备数量灵活定制调度策略，适配工厂原料仓、成品仓、电商分拣仓等场景。

AGV 智能仓储调度平台适合智能制造工厂、电商物流中心、医药、汽配仓储等企业开展自动化改造。源码仅作技术学习研究，项目落地需要结合现场环境调试导航参数，保障网络稳定，规范设备运维流程，遵守工业设备安全规范，确保仓储自动化作业安全稳定运行。
